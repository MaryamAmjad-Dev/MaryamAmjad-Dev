**Hybrid AI Router | AMD Developer Hackathon: ACT II | Team Shaheen**

An AI routing system designed to reduce cloud inference costs under constrained hardware conditions.

- Designed for a 4 GB RAM, 2 vCPU environment without a GPU.

- Uses a validation gate to help determine when complex or unsuccessful tasks require cloud escalation.
- Applies prompt pruning to achieve reported cloud-token savings of 10% to 30%.

**Stack:** Python, Docker, llama.cpp, Qwen 2.5 3B, Fireworks API, Next.js, Tailwind CSS.
